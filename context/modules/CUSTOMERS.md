# Customers Module Context

## 1. Overview
The Customers module tracks corporate clients, business sub-ventures, KYC documentation, and client SPOC contacts.
- Module UUID: `4e57fd71-b53e-43c0-862e-5698e09c0922` (`customers` / `customer`)
- Submodule: Customer Detail (`a7e6b014-9f4a-4d2c-87d2-431527ef9a10`)

## 2. Key Capabilities
- Sub-venture management: Create/edit sub-ventures with KYC document uploads and contact persons.
- Client SPOC: Group SPOC details (name, email, phone, designation).
- Engagement Manager & Sales Manager assignment per customer.
